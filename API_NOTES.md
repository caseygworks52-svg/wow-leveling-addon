# WoW: Forever 1.60.1 API notes

- \`C_QuestLog.GetAllCompletedQuestIDs()\`: sorted array of completed quest IDs; published API reference lists Forever 1.60.1 support. https://warcraft.wiki.gg/wiki/API_C_QuestLog.GetAllCompletedQuestIDs
- \`C_QuestLog.IsQuestFlaggedCompleted(questID)\`: boolean completion check; published API reference lists Forever 1.60.1 support. https://warcraft.wiki.gg/wiki/API:C_QuestLog.IsQuestFlaggedCompleted

A completed ID represents a quest completed and turned in; active quest-log entries remain a separate source. Published docs verify API availability, not full addon flow, map accuracy, quest route completeness, or in-client behavior. Live character testing is still required.
